# PostsWebApp

> Веб-приложение для управления публикациями и авторизации пользователей на Java Spring Boot.

**Автор:** Туров Олег, 11.1-621

## Быстрый старт

```bash
git clone <url-репозитория>
cd TUROV-PP-TASK-1
mvn spring-boot:run
```

## Ключевые особенности

- **Авторизация и сессии:** Безопасная регистрация, вход и управление сессиями через Spring JDBC и куки.
- **Лента публикаций:** Создание и просмотр постов в реальном времени.
- **Миграции БД:** Автоматическое управление схемой через Liquibase.
- **Локализация:** Поддержка нескольких языков (`ru`, `en`).
