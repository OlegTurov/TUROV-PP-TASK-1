## Описание

Веб-приложение написанное на Java с возможностью регистрации и авторизации,
созданием постов(сообщений), которые обновляются в реальном времени.

## Технологии

Java 17, Spring Boot, liquibase, postgresql, Spring Web, thymeleaf, Spring JDBC
