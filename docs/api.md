# API Reference

Описание веб-эндпоинтов и маршрутов приложения **PostsWebApp**.

## Аутентификация и авторизация

Доступ к защищенным страницам (например, `/posts`) требует наличия действительной сессии (кука `SESSION_ID`).

### Эндпоинты аутентификации

| Метод | Путь | Описание |
|-------|------|----------|
| `GET` | `/register` | Страница регистрации нового пользователя |
| `POST` | `/register` | Регистрация пользователя (`email`, `password`) |
| `GET` | `/login` | Страница входа в систему |
| `POST` | `/login` | Аутентификация и установка куки `SESSION_ID` |
| `POST` | `/logout` | Завершение сеанса и удаление куки |

## Публикации (Posts)

| Метод | Путь | Описание | Требуется сессия |
|-------|------|----------|------------------|
| `GET` | `/posts` | Просмотр ленты публикаций и создание поста | Да |
| `POST` | `/posts` | Создание новой публикации (`text`) | Да |

## Локализация

Приложение поддерживает мультиязычность (файлы локализации `messages.properties`, `messages_ru.properties`, `messages_en.properties`).
